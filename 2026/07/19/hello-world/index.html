你好，世界！👋

欢迎来到我的个人博客！这里是 aidon 的数字花园，用于记录编程、数学与生活中的思考。

关于这个博客

本博客基于以下技术栈搭建：

组件 技术选型 说明
框架 Hexo 7.x 快速、简洁且高效的 Node.js 静态博客框架
主题 Butterfly 美观、功能丰富的 Hexo 主题
托管 GitHub Pages 免费、稳定的静态网站托管服务
CI/CD GitHub Actions 自动构建与部署流水线
公式 MathJax 支持 LaTeX 数学公式渲染
搜索 本地搜索 基于 hexo-generator-searchdb 的客户端搜索

博客功能

  • 📝 Markdown 写作 — 使用纯 Markdown 撰写文章，专注内容创作
  • 📐 LaTeX 公式 — 支持行内公式与块级公式，适合学术写作
  • 🖼️ 相册/图集 — 内置相册功能，方便展示图片
  • 🏷️ 分类 & 标签 — 灵活的文章分类与标签系统
  • 📅 时间线归档 — 按时间归档，方便回溯历史文章
  • 🔍 本地搜索 — 无需后端服务的全文搜索
  • 🌙 暗色模式 — 自动/手动切换明暗主题

致谢

感谢 Hexo 团队和 Butterfly 主题作者 Jerry 的出色工作。

种一棵树最好的时间是十年前，其次是现在。
